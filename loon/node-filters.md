# Loon 节点筛选器

本文件记录 Loon 的节点筛选规则，以及可直接写入配置文件的 `[Remote Filter]` 配置段。

筛选方式统一使用：`NameRegex`。筛选器不限定订阅来源，匹配 Loon 中所有已导入订阅的节点；新增订阅后也纳入筛选范围。筛选器按地区与节点类型组合，策略组直接引用筛选器名称。

## 分类原则

- 普通节点：按地区匹配，排除倍率大于 2 的节点。
- 家宽节点：按地区匹配家宽关键词；不创建香港家宽筛选器。
- 专线节点：按地区匹配 `IPLC` 或 `IEPL`。
- 高倍率节点：不区分地区，统一匹配倍率严格大于 2 的节点，供手动选择。
- **允许跨池重叠**：家宽与专线可以同时进入两个池；家宽、专线节点也可以进入高倍率池。
- 普通池只排除大于 2 倍的节点，不排除家宽或专线。因此普通的 1x、2x 家宽/专线节点仍可进入普通池。
- 暂不创建全量地区筛选器。

## 地区关键词

- 香港：`香港|Hong Kong|HK`
- 日本：`日本|Japan|JP`
- 台湾：`台湾|台灣|Taiwan|TW`
- 韩国：`韩国|韓國|Korea|KR`
- 美国：`美国|美國|United States|USA|US`
- 新加坡：`新加坡|Singapore|SG`

地区简称使用边界匹配，避免把 `HK`、`US` 等误识别为其他单词的一部分。实际节点名称如果使用其他缩写，需要按订阅里的真实命名补充。

## 倍率规则

高倍率定义为严格大于 2 倍，例如 `2.1x`、`2.5x`、`3x`、`4.5倍`。不匹配 `2x`、`2.0x` 或 `2倍`。

倍率表达式：

```regex
(?:2\.(?:0*[1-9][0-9]*)|[3-9](?:\.[0-9]+)?|[1-9][0-9]+(?:\.[0-9]+)?)\s*(?:x|倍)
```

当前按节点名称中带 `x` 或 `倍` 的倍率标记识别。若机场使用其他写法，需按实际命名补充。

## 筛选器清单：18 个

- 普通节点池：6 个。
- 家宽节点池：5 个，不含香港。
- 专线节点池：6 个。
- 高倍率节点池：1 个，不区分地区。

## 可直接写入配置文件的完整筛选器

将以下配置段整体放入 Loon 配置文件。若配置文件已经有 `[Remote Filter]`，只复制下面段落中的规则行，不要重复添加段标题。

```ini
[Remote Filter]

# ==============================
# 普通节点：按地区匹配，排除大于 2 倍
# 保留 1x、2x，以及普通家宽/专线节点
# ==============================

普通-香港 = NameRegex, FilterKey = "(?i)^(?=.*(?:香港|Hong Kong|(?:^|[^A-Za-z])HK(?:$|[^A-Za-z])))(?!.*(?:2\.(?:0*[1-9][0-9]*)|[3-9](?:\.[0-9]+)?|[1-9][0-9]+(?:\.[0-9]+)?)\s*(?:x|倍)).*$"
普通-日本 = NameRegex, FilterKey = "(?i)^(?=.*(?:日本|Japan|(?:^|[^A-Za-z])JP(?:$|[^A-Za-z])))(?!.*(?:2\.(?:0*[1-9][0-9]*)|[3-9](?:\.[0-9]+)?|[1-9][0-9]+(?:\.[0-9]+)?)\s*(?:x|倍)).*$"
普通-台湾 = NameRegex, FilterKey = "(?i)^(?=.*(?:台湾|台灣|Taiwan|(?:^|[^A-Za-z])TW(?:$|[^A-Za-z])))(?!.*(?:2\.(?:0*[1-9][0-9]*)|[3-9](?:\.[0-9]+)?|[1-9][0-9]+(?:\.[0-9]+)?)\s*(?:x|倍)).*$"
普通-韩国 = NameRegex, FilterKey = "(?i)^(?=.*(?:韩国|韓國|Korea|(?:^|[^A-Za-z])KR(?:$|[^A-Za-z])))(?!.*(?:2\.(?:0*[1-9][0-9]*)|[3-9](?:\.[0-9]+)?|[1-9][0-9]+(?:\.[0-9]+)?)\s*(?:x|倍)).*$"
普通-美国 = NameRegex, FilterKey = "(?i)^(?=.*(?:美国|美國|United States|(?:^|[^A-Za-z])USA(?:$|[^A-Za-z])|(?:^|[^A-Za-z])US(?:$|[^A-Za-z])))(?!.*(?:2\.(?:0*[1-9][0-9]*)|[3-9](?:\.[0-9]+)?|[1-9][0-9]+(?:\.[0-9]+)?)\s*(?:x|倍)).*$"
普通-新加坡 = NameRegex, FilterKey = "(?i)^(?=.*(?:新加坡|Singapore|(?:^|[^A-Za-z])SG(?:$|[^A-Za-z])))(?!.*(?:2\.(?:0*[1-9][0-9]*)|[3-9](?:\.[0-9]+)?|[1-9][0-9]+(?:\.[0-9]+)?)\s*(?:x|倍)).*$"


# ==============================
# 家宽节点：按地区匹配家宽关键词
# 不创建香港家宽筛选器
# ==============================

家宽-日本 = NameRegex, FilterKey = "(?i)^(?=.*(?:日本|Japan|(?:^|[^A-Za-z])JP(?:$|[^A-Za-z])))(?=.*(?:家宽|家庭宽带|住宅|Residential|原生真家宽|原生家宽|真家宽)).*$"
家宽-台湾 = NameRegex, FilterKey = "(?i)^(?=.*(?:台湾|台灣|Taiwan|(?:^|[^A-Za-z])TW(?:$|[^A-Za-z])))(?=.*(?:家宽|家庭宽带|住宅|Residential|原生真家宽|原生家宽|真家宽)).*$"
家宽-韩国 = NameRegex, FilterKey = "(?i)^(?=.*(?:韩国|韓國|Korea|(?:^|[^A-Za-z])KR(?:$|[^A-Za-z])))(?=.*(?:家宽|家庭宽带|住宅|Residential|原生真家宽|原生家宽|真家宽)).*$"
家宽-美国 = NameRegex, FilterKey = "(?i)^(?=.*(?:美国|美國|United States|(?:^|[^A-Za-z])USA(?:$|[^A-Za-z])|(?:^|[^A-Za-z])US(?:$|[^A-Za-z])))(?=.*(?:家宽|家庭宽带|住宅|Residential|原生真家宽|原生家宽|真家宽)).*$"
家宽-新加坡 = NameRegex, FilterKey = "(?i)^(?=.*(?:新加坡|Singapore|(?:^|[^A-Za-z])SG(?:$|[^A-Za-z])))(?=.*(?:家宽|家庭宽带|住宅|Residential|原生真家宽|原生家宽|真家宽)).*$"


# ==============================
# 专线节点：按地区匹配 IPLC / IEPL
# 允许与家宽、高倍率池重叠
# ==============================

专线-香港 = NameRegex, FilterKey = "(?i)^(?=.*(?:香港|Hong Kong|(?:^|[^A-Za-z])HK(?:$|[^A-Za-z])))(?=.*(?:IPLC|IEPL)).*$"
专线-日本 = NameRegex, FilterKey = "(?i)^(?=.*(?:日本|Japan|(?:^|[^A-Za-z])JP(?:$|[^A-Za-z])))(?=.*(?:IPLC|IEPL)).*$"
专线-台湾 = NameRegex, FilterKey = "(?i)^(?=.*(?:台湾|台灣|Taiwan|(?:^|[^A-Za-z])TW(?:$|[^A-Za-z])))(?=.*(?:IPLC|IEPL)).*$"
专线-韩国 = NameRegex, FilterKey = "(?i)^(?=.*(?:韩国|韓國|Korea|(?:^|[^A-Za-z])KR(?:$|[^A-Za-z])))(?=.*(?:IPLC|IEPL)).*$"
专线-美国 = NameRegex, FilterKey = "(?i)^(?=.*(?:美国|美國|United States|(?:^|[^A-Za-z])USA(?:$|[^A-Za-z])|(?:^|[^A-Za-z])US(?:$|[^A-Za-z])))(?=.*(?:IPLC|IEPL)).*$"
专线-新加坡 = NameRegex, FilterKey = "(?i)^(?=.*(?:新加坡|Singapore|(?:^|[^A-Za-z])SG(?:$|[^A-Za-z])))(?=.*(?:IPLC|IEPL)).*$"


# ==============================
# 高倍率节点：不区分地区，倍率严格大于 2
# 家宽、专线节点允许同时进入高倍率池
# ==============================

高倍率节点 = NameRegex, FilterKey = "(?i)^(?=.*(?:2\.(?:0*[1-9][0-9]*)|[3-9](?:\.[0-9]+)?|[1-9][0-9]+(?:\.[0-9]+)?)\s*(?:x|倍)).*$"
```

## 创建后检查

建议在 Loon 中用以下节点名检查匹配结果：

- `香港01`：进入普通-香港。
- `香港A1 2x`：进入普通-香港，不进入高倍率-香港。
- `香港HKBN-原生家宽-A 2.5x`：进入高倍率节点池；香港家宽筛选器不存在。
- `韩国原生真家宽晚6点换ip`：进入家宽-韩国。
- `日本家宽-IEPL2`：同时进入家宽-日本和专线-日本。
- `HK-IEPL-A 4.5x`：进入专线-香港和高倍率节点池，不进入普通-香港。

以上正则根据目前提供的节点命名样本整理，仍需在 Loon 中验证实际匹配结果。
