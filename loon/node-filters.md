# Loon 节点筛选器

本文件记录需要在 Loon App「配置 → 筛选节点」中手动创建的筛选器。它不是可直接导入的配置段。

筛选方式统一选择：`NameRegex`。

## 分类原则

- 普通节点：按地区匹配，排除倍率大于 2 的节点。
- 家宽节点：按地区匹配家宽关键词；香港家宽不收录。
- 专线节点：按地区匹配 `IPLC` 或 `IEPL`。
- **允许跨池重叠**：家宽专线可以同时进入家宽池和专线池；家宽高倍率也可以进入家宽池；专线高倍率也可以进入专线池。
- 普通池只排除大于 2 倍的节点，不排除家宽或专线。因此普通的 1x、2x 家宽/专线节点仍可进入普通池。

## 倍率规则

识别大于 2 的倍率标记，例如 `2.5x`、`3x`、`4.5倍`。不排除 `2x` 或 `2倍`。

通用倍率表达式：

```regex
(?:2\.[1-9][0-9]*|[3-9](?:\.[0-9]+)?|[1-9][0-9]+(?:\.[0-9]+)?)(?:x|倍)
```

## 地区关键词

- 香港：`香港|Hong Kong|HK`
- 日本：`日本|Japan|JP`
- 台湾：`台湾|台灣|Taiwan|TW`
- 韩国：`韩国|韓國|Korea|KR`
- 美国：`美国|美國|United States|USA|US`
- 新加坡：`新加坡|Singapore|SG`

实际节点名称如果使用其他缩写，需要按订阅里的真实命名补充。特别是 `JP`、`US` 等短缩写可能与其他文字重合，筛选结果应在 Loon 中实际检查。

## 17 个筛选器

### 普通节点池（6 个）

共同逻辑：包含对应地区关键词，且名称中没有大于 2 的倍率标记。

| 筛选器名称 | NameRegex |
|---|---|
| 普通-香港 | `^(?=.*(?:香港|Hong Kong|HK))(?!.*(?:2\.[1-9][0-9]*|[3-9](?:\.[0-9]+)?|[1-9][0-9]+(?:\.[0-9]+)?)(?:x|倍)).*$` |
| 普通-日本 | `^(?=.*(?:日本|Japan|JP))(?!.*(?:2\.[1-9][0-9]*|[3-9](?:\.[0-9]+)?|[1-9][0-9]+(?:\.[0-9]+)?)(?:x|倍)).*$` |
| 普通-台湾 | `^(?=.*(?:台湾|台灣|Taiwan|TW))(?!.*(?:2\.[1-9][0-9]*|[3-9](?:\.[0-9]+)?|[1-9][0-9]+(?:\.[0-9]+)?)(?:x|倍)).*$` |
| 普通-韩国 | `^(?=.*(?:韩国|韓國|Korea|KR))(?!.*(?:2\.[1-9][0-9]*|[3-9](?:\.[0-9]+)?|[1-9][0-9]+(?:\.[0-9]+)?)(?:x|倍)).*$` |
| 普通-美国 | `^(?=.*(?:美国|美國|United States|USA|US))(?!.*(?:2\.[1-9][0-9]*|[3-9](?:\.[0-9]+)?|[1-9][0-9]+(?:\.[0-9]+)?)(?:x|倍)).*$` |
| 普通-新加坡 | `^(?=.*(?:新加坡|Singapore|SG))(?!.*(?:2\.[1-9][0-9]*|[3-9](?:\.[0-9]+)?|[1-9][0-9]+(?:\.[0-9]+)?)(?:x|倍)).*$` |

### 家宽节点池（5 个，不含香港）

共同逻辑：包含家宽关键词和对应地区关键词；排除香港。家宽节点即使同时带有 IEPL/IPLC 或大于 2 倍标记，也仍进入家宽池。

家宽关键词：`家宽|家庭宽带|住宅|Residential|原生真家宽`

| 筛选器名称 | NameRegex |
|---|---|
| 家宽-日本 | `^(?=.*(?:日本|Japan|JP))(?=.*(?:家宽|家庭宽带|住宅|Residential|原生真家宽))(?!.*(?:香港|Hong Kong|HK)).*$` |
| 家宽-台湾 | `^(?=.*(?:台湾|台灣|Taiwan|TW))(?=.*(?:家宽|家庭宽带|住宅|Residential|原生真家宽))(?!.*(?:香港|Hong Kong|HK)).*$` |
| 家宽-韩国 | `^(?=.*(?:韩国|韓國|Korea|KR))(?=.*(?:家宽|家庭宽带|住宅|Residential|原生真家宽))(?!.*(?:香港|Hong Kong|HK)).*$` |
| 家宽-美国 | `^(?=.*(?:美国|美國|United States|USA|US))(?=.*(?:家宽|家庭宽带|住宅|Residential|原生真家宽))(?!.*(?:香港|Hong Kong|HK)).*$` |
| 家宽-新加坡 | `^(?=.*(?:新加坡|Singapore|SG))(?=.*(?:家宽|家庭宽带|住宅|Residential|原生真家宽))(?!.*(?:香港|Hong Kong|HK)).*$` |

### 专线节点池（6 个）

共同逻辑：包含对应地区关键词，以及 `IPLC` 或 `IEPL`。即使同时带有家宽或大于 2 倍标记，也仍进入专线池。

| 筛选器名称 | NameRegex |
|---|---|
| 专线-香港 | `^(?=.*(?:香港|Hong Kong|HK))(?=.*(?:IPLC|IEPL)).*$` |
| 专线-日本 | `^(?=.*(?:日本|Japan|JP))(?=.*(?:IPLC|IEPL)).*$` |
| 专线-台湾 | `^(?=.*(?:台湾|台灣|Taiwan|TW))(?=.*(?:IPLC|IEPL)).*$` |
| 专线-韩国 | `^(?=.*(?:韩国|韓國|Korea|KR))(?=.*(?:IPLC|IEPL)).*$` |
| 专线-美国 | `^(?=.*(?:美国|美國|United States|USA|US))(?=.*(?:IPLC|IEPL)).*$` |
| 专线-新加坡 | `^(?=.*(?:新加坡|Singapore|SG))(?=.*(?:IPLC|IEPL)).*$` |

## 创建后检查

建议先创建并检查以下代表性节点：

- `香港01`：进入普通-香港。
- `香港A1 2x`：进入普通-香港。
- `香港HKBN原生家宽-A 2.5x`：不进入普通-香港；香港家宽筛选器不存在。
- `韩国原生真家宽`：进入家宽-韩国。
- `日本家宽-IEPL2`：同时进入家宽-日本和专线-日本。
- `HK-IEPL-A 4.5x`：进入专线-香港，不进入普通-香港。

注意：以上正则根据目前提供的节点命名样本整理，仍需在 Loon 中验证实际匹配结果。若机场节点名使用不同地区缩写或家宽关键词，应根据真实名称补充关键词。
