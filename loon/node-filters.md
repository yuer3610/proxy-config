# Loon 节点筛选器

本文件记录 Loon 的节点筛选规则及可写入配置文件的 `[Remote Filter]` 配置段。

筛选方式统一使用：`NameRegex`。筛选器按地区与节点类型组合，策略组后续直接引用筛选器名称。

## 分类原则

- 普通节点：按地区匹配，排除倍率大于 2 的节点。
- 家宽节点：按地区匹配家宽关键词；不创建香港家宽筛选器。
- 专线节点：按地区匹配 `IPLC` 或 `IEPL`。
- 高倍率节点：按地区匹配倍率大于 2 的节点。
- **允许跨池重叠**：家宽与专线可以同时进入两个池；家宽、专线节点也可以进入高倍率池。
- 普通池只排除大于 2 倍的节点，不排除家宽或专线。因此普通的 1x、2x 家宽/专线节点仍可进入普通池。
- 暂不创建全量地区筛选器。

## 地区关键词

- 香港：`香港|Hong Kong|HK`
- 日本：`日本|Japan|JP`
- 台湾：`台湾|台灣|Taiwan|TW`
- 韩国：`韩国|韓國|Korea|KR`
- 美国：`美国|美國|United States|USA|US`
- 新加坡：`新加坡|Singapore|SG`

地区简称使用边界匹配，避免把 `HK`、`US` 等误识别为其他单词的一部分。实际节点名称如果使用其他缩写，需要按订阅里的真实命名补充。

## 倍率规则

高倍率定义为严格大于 2 倍，例如 `2.1x`、`2.5x`、`3x`、`4.5倍`。不匹配 `2x`、`2.0x` 或 `2倍`。

通用倍率表达式：

```regex
(?:2\.(?:0*[1-9][0-9]*)|[3-9](?:\.[0-9]+)?|[1-9][0-9]+(?:\.[0-9]+)?)\s*(?:x|倍)
```

当前按节点名称中带 `x` 或 `倍` 的倍率标记识别。若机场使用其他写法，需按实际命名补充。

## 筛选器清单：23 个

- 普通节点池：6 个。
- 家宽节点池：5 个，不含香港。
- 专线节点池：6 个。
- 高倍率节点池：6 个。

## 可直接写入配置文件的高倍率筛选器

将以下内容追加到现有配置的 `[Remote Filter]` 段中。若文件已有该段，不要重复添加段标题。

```ini
高倍率-香港 = NameRegex, FilterKey = "(?i)^(?=.*(?:香港|Hong Kong|(?:^|[^A-Za-z])HK(?:$|[^A-Za-z])))(?=.*(?:2\\.(?:0*[1-9][0-9]*)|[3-9](?:\\.[0-9]+)?|[1-9][0-9]+(?:\\.[0-9]+)?)\\s*(?:x|倍)).*$"
高倍率-日本 = NameRegex, FilterKey = "(?i)^(?=.*(?:日本|Japan|(?:^|[^A-Za-z])JP(?:$|[^A-Za-z])))(?=.*(?:2\\.(?:0*[1-9][0-9]*)|[3-9](?:\\.[0-9]+)?|[1-9][0-9]+(?:\\.[0-9]+)?)\\s*(?:x|倍)).*$"
高倍率-台湾 = NameRegex, FilterKey = "(?i)^(?=.*(?:台湾|台灣|Taiwan|(?:^|[^A-Za-z])TW(?:$|[^A-Za-z])))(?=.*(?:2\\.(?:0*[1-9][0-9]*)|[3-9](?:\\.[0-9]+)?|[1-9][0-9]+(?:\\.[0-9]+)?)\\s*(?:x|倍)).*$"
```

## 创建后检查

建议在 Loon 中用以下节点名检查匹配结果：

- `香港01`：进入普通-香港。
- `香港A1 2x`：进入普通-香港，不进入高倍率-香港。
- `香港HKBN-原生家宽-A 2.5x`：进入高倍率-香港；香港家宽筛选器不存在。
- `韩国原生真家宽晚6点换ip`：进入家宽-韩国。
- `日本家宽-IEPL2`：同时进入家宽-日本和专线-日本。
- `HK-IEPL-A 4.5x`：进入专线-香港和高倍率-香港，不进入普通-香港。

以上正则根据目前提供的节点命名样本整理，仍需在 Loon 中验证实际匹配结果。
